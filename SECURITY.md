# Security Policy

## Reporting Security Vulnerabilities

We take the security of ContextShield seriously. If you discover or suspect a security vulnerability within ContextShield, please report it responsibly.

### How to Report

- **Preferred Method**: Submit a private vulnerability report directly through GitHub's Security Advisories tab on the repository (`Security > Report a vulnerability`).
- Please provide a detailed description of the issue, including steps to reproduce, sample payloads, and the affected components (e.g., Scanner, Sanitizer, Risk Engine, Gateway, or LiveKit Worker).
- Please **do not** open public GitHub issues or disclose vulnerability details publicly before a resolution is coordinated.

### Policy & Scope

- ContextShield is a zero-latency defense gateway designed to mitigate prompt injection, instruction overrides, and sensitive data exfiltration before external context reaches downstream AI agents.
- All reports will be acknowledged promptly and reviewed with highest priority.
